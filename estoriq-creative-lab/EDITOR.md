# Estoriq visual editor (QC only)

Start with npm install and npm run dev. Open /?mode=editor to edit in Puck. Drag and rearrange seven editable section blocks, change text, service/project data, and image URLs. Use the built-in Publish action to SAVE A DRAFT TO LOCAL BROWSER STORAGE only. Preview works on the same device. Export JSON and supply it to development to review and integrate; it will not automatically change source code or GitHub.

IMPORTANT: this is a component-based builder, not pixel-perfect freeform Figma. Text, photos, services, projects and section ordering can be edited; full redesign of JSX/components still requires development. Assets are HTTPS URLs; there is not yet authenticated image upload, remote CMS, multi-device cloud sync, or production publishing. Don't treat local drafts as durable backups; export JSON regularly. Do not publish the website without approval.
